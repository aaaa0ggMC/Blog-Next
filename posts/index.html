P1228 地毯填补问题
题目描述

相传在一个古老的阿拉伯国家里，有一座宫殿。宫殿里有个四四方方的格子迷宫，国王选择驸马的方法非常特殊，也非常简单：公主就站在其中一个方格子上，只要谁能用地毯将除公主站立的地方外的所有地方盖上，美丽漂亮聪慧的公主就是他的人了。公主这一个方格不能用地毯盖住，毯子的形状有所规定，只能有四种选择（如图）：

并且每一方格只能用一层地毯，迷宫的大小为 2k×2k2^k\times 2^k2k×2k 的方形。当然，也不能让公主无限制的在那儿等，对吧？由于你使用的是计算机，所以实现时间为 111 秒。

输入格式

输入文件共 222 行。

第一行一个整数 kkk，即给定被填补迷宫的大小为 2k×2k2^k\times 2^k2k×2k（0<k≤100\lt k\leq 100<k≤10）； 第二行两个整数 x,yx,yx,y，即给出公主所在方格的坐标（xxx 为行坐标，yyy 为列坐标），xxx 和 yyy 之间有一个空格隔开。

输出格式

将迷宫填补完整的方案：每一补（行）为 x y cx\ y\ cx y c（x,yx,yx,y 为毯子拐角的行坐标和列坐标，ccc 为使用毯子的形状，具体见上面的图 111，毯子形状分别用 1,2,3,41,2,3,41,2,3,4 表示，x,y,cx,y,cx,y,c 之间用一个空格隔开）。

探索过程

按照这个题目的 Tag 应该就是利用“分治”去处理每一块地方了，唉，可惜我是个傻逼，总是会在分区这里绕来绕去，因此也是折腾很久出来这个做法：

// https://www.luogu.com.cn/problem/solution/P1228
#include <iostream>

// 小地毯
//  1  2   33  44
// 11  22   3  4
// 拼接成为大地毯
// 0033
// 0013
// 2111  其他的基本上对称
// 2211
//
// 对着中间的 3/4 补一个 L 地毯，这样四个小区域都有一个 L 地毯了 

int main() {
    std::size_t k;
    std::cin >> k;

    std::size_t p_x,p_y;
    std::cin >> p_x >> p_y;

    std::size_t width = 1 << k;
    auto dfs = [](auto && self, std::size_t px, std::size_t py, std::size_t bx, std::size_t by, std::size_t len) {
        // 切分成 1*1 区域就没必要了
        if(len == 1) return;
        
        // 将 px,py 变换到 bx,by,len 的区域内算出象限
        // 其中 (center_x,center_y) 固定处在第四象限
        std::size_t half = len >> 1;
        std::size_t center_x = bx + half;
        std::size_t center_y = by + half;

        auto out = [&](int off_x, int off_y, int type){
            std::cout << (int(center_x) - off_x) << " " << (int(center_y) - off_y) << " " << type << "\n"; 
        };
        
        //          |
        //          |
        // ----------(center_x,center_y)-------
        //          |
        //          |
        int off_x = !(px < center_x);
        int off_y = !(py < center_y);
        // x = 0 左边， x=1 右边  
        // y = 0 上面， y=1 下面
        // yx
        // 00 : 特殊点在左上角，放 1
        // 10 : 特殊点在左下角，放 2
        // 11 : 特殊点右下角，放 4，因此为 off_x | off_y*2  + 1
        int index = ((off_x << 1) | off_y);

        out(off_x, off_y, index + 1);

        // 中间四个老演员
        std::size_t x_s[] = { center_x - 1, center_x - 1, center_x, center_x };
        std::size_t y_s[] = { center_y - 1, center_y, center_y - 1, center_y };
        
        // 替换一个，因为已经有了
        x_s[index] = px;
        y_s[index] = py;

        self(self, x_s[0], y_s[0], bx, by, half);
        self(self, x_s[1], y_s[1], bx, center_y, half);
        self(self, x_s[2], y_s[2], center_x, by, half); 
        self(self, x_s[3], y_s[3], center_x, center_y, half); 
    };
    

    dfs(dfs, p_x, p_y, 1, 1, width);
}
