# 逆向与MCP

折腾 OpenRouter 的过程中我不知是不是开窍了，加上我们班级在选课上可谓是混乱至极，别说选课冲突了，我连去哪儿上课都会一下就忘了。于是我准备写个 MCP 为自己的 Rikkahub 注入更多功能。

这个 MCP 叫做 (MCP-Schedule-Termux)[https://github.com/aaaa0ggMC/mcp-schedule-termux]，当然名字带 termux 不意味着只能运行在 termux，你还是可以接入比如 Hermes 甚至 Codex 之类的Agent的。

这个 MCP 最核心的就是支持上课查询，其次便是十分灵活的贴合学生的 schedule。比如中秋国庆放假，你只需要把群里消息发给AI，AI mutate一下数据就可以让课表立马作出调整。这是目前手机助手很难做到的，也是目前学校风靡的 Hustoday 无法做到的<span class="ps">（不过最近正在猛猛开发的冰岩开放平台正在试图解决这个问题，但目前对于我而言，还是自己指挥 AI 搓一个 MCP 最自在哈哈）</span>。

用着用着我就爽起来了，放到API里属于是使用较少的隐私（也许会泄漏啥的/在编程的过程中上传到模型服务器）换取商业软件都做不到的便利了。因此我也是一鼓作气打算给自己做一个账本MCP用来管理账本（由于这个涉及隐私比较多，因此我还没完善的话就先不开源了 <span class="ps">实际上是AI自己给我创建了private repo，虽然每次push我都审核了没上传隐私，但是目前我暂时是懒得管</span> ）。微信和支付宝的消费记录可以导出，整体而言虽然缺乏时效性，但能合法得到自己的数据谁不喜欢？

把支付宝和微信做完后我突然想到了一个 hardnut : 我的学校消费记录怎么导出？ 学校的流水查询只能在一个界面简陋到极致的企业微信界面里面查看，而且内容还十分垃圾，最主要的就是 —— 根本无法导出！！ 东想西想，我决定逆向这个流水查询的网页，暴露出 nodejs API 给自己用。

不过我并不是逆向大蛇，我上次使用知名的逆向工具还是 Linux 界的“黑客”系统 Kali，当时我打开了 BurpSuit然后看着令人眼花缭乱的界面发呆后就关闭了。因此我只会这些步骤：

1. 打开企业微信到相应页面，关闭网络后点击浏览器查看<span class="ps">（关闭网络可以阻止跳转从而得到第一级地址）</span>， KDE Connect 发送网址给电脑
2. 电脑开启无痕浏览以及DevTools访问页面，然后看着界面闪来闪去到了学校CAS系统
3. 输入账号密码验证码，登录后成功看到自己的流水
4. 开始像个吗喽在 requests 中寻找跳转，寻找 JSESSIONID ，然后往自己的简易 axios 脚本（axios也是找AI现学的）写入一些地址
5. 剩下的交给 AI 去试错成功认证得到CASTGC
6. 让它做成 SDK
7. 终于获取了流水了

回过头来才发现学校的登录门户不知不觉就被逆向了...... 既然都这样了，我觉得SDK只能获取流水也确实比较拉胯，于是我又开启吗喽监视，把我觉得很常用的平台都逆向了，做成了一个 SDK [HustHelper](https://github.com/aaaa0ggMC/husthelper).

这里简要讲一下支持什么平台以及啥，如果你也是 Huster 然后也有需求并且自己或者AI也会一点点 nodejs，可以看看：

- ecard 一卡通信息，流水，校园卡余额
- mhub  教务处信息，包含成绩，空闲教室啥的
- one.hust 数智华科大，杂七杂八的信息
- smartcourse 课程信息
- ihuster 二课成绩
- pejxxx 体育类，包括你过去场馆预约查询，以及你课外锻炼次数（这个只能在学期末才能看到当前学期的）
- register 看看自己注册没有，实用度约等于0
- hkwxy 看看网络设备
- selfverice 另一个网络服务平台
- electricity 电费获取 
- aggregated 简要聚合了一下上面杂七在八的平台

总之做完后我也是燃尽了...... 接着蓦然回首发现自己这么多功能其实很多都不需要，那就开源吧，我这个做的都是只读的，风险应该不大。
