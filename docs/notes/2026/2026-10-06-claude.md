# 如何如何，沉迷 Claude

虽然 Anthrohpic 不是人，当时它真的富有啊。只要你的账号不被封禁，订阅 Claude 真的是目前这么多 AI Plan 里最好的，我说实话。

你可能会拿大家都吹捧的 Codex 来反驳，说"Tibo 这么频繁的重置难道还不舒服吗？"。但我得说，实践才是检验真理的唯一标准好吧。我两个 Plan 目前都持有：

<Img content="/lHw6xDEAV_x30J-r4A60ygDqRNMJAK99WuHpWytgObEvZWqhPFq8Xg.png" alt="GPT 订阅" />
<Img content="/CeD_lI909nIUIcVA0LtYhUxL9nGOk6xuSAZQHq7lClW25ClrLpciK9I.png" alt="Claude 订阅" />

刚开始我使用 Codex 进行试水，我还以为是我项目太复杂（一个图形学项目），因此大部分时候我还是使用 DeepSeek/Step 进行编程，GPT 则被我代理到了手机上用于 Rikkahub 聊天。

直到我这个月订阅了 Claude，我的天啊，我才突然发现原来纯纯是 GPT 额度低。我就算是配置了 deputy（即模型可以把杂活派发给 Step 做），拿GPT 5.6 Sol，30min 额度就没了，而使用 Claude 我可以连续干 3 个小时使用 Opus 5.5，使用 Sonnet 更是实现了循环。

## 重置&额度

大家都说 Claude 重置小气，但是从这方面我觉得都是 20 usd，Claude 能够让你不用太在意重置这件事。

另一方面，不知道是不是最近在推 Cloud Session 和新出的 Project，也是直接赠送了我 100usd Cloud Session + 限时24h 100usd Project Credits.

<Img content="/iT5cTcoiU2LUPFGyRH4gHA0PdSctWTtxNoqvvjuhu_6TeBMWa_2MBAY-.png" alt="额度" />

这有多离谱你看出来了吗？买 20usd 送名义上的 200usd. Cloud Session 和 Project 都自带比较完整的虚拟机，你纯蹭羊毛的话让模型勤 push 就行了，切换平台也基本没啥阻力。

现在回到 Codex，重置真的是件好事吗？

个人认为不是，首先便是额度本来就很低，吃满 5h 额度太容易，几个 5h 额度吃满后周额度就没了，高强度使用两天都不到就见底了，中间还有大半时间是被 5h 额度卡着的。那么 Tibo 重置给 Plus 用户的收益其实是远小于 Pro 的。加上 Codex 重置不比 Claude 重置，Claude 重置不影响其本来的重置时间，而 Codex 无论是你使用重置卡还是 Tibo 定时重置都会把你本来的重置时间重新计算。导致你如果不在重置前猛蹬完，那你就亏了。

这依旧是利好 Pro，对 Plus 惩罚很大。加上最近 Codex 对于 Pro 也进行了额度衰减，这让 Codex 对我的吸引力越来越低了。可能 ChatGPT 的 ChatGPT Live 还有点吸引力但是我订阅是为了编程啊喂！

## 模型水平

### 智力
首先，大部分评测表明 Claude Opus 5.5 以及 Claude Sonnet 5.5 的智力水平是高于 GPT 5.6 Sol 和 GPT 6.1 Sol的。那问题来了，我要找谁对比？

GPT 6 Astra吗？那确实比不上，但是GPT 6 Astra额度消耗更是不用说了好吧，只需10min 5h额度光速见底。

因此 Claude 提供的模型平均水平就比 GPT 好不少。

### 体感
个人觉得 GPT 太 Nerd 了。和 Claude 模型进行沟通就轻松许多。当然我这里不是说 Nerd 能力不行，就是说和 GPT 沟通太麻烦了。

这里 Claude 进行了测试，虽然有王婆卖瓜自卖自夸之嫌，但是我认可了！

## 总结

Claude 体验就是比 Codex 好，导致我现在都有点沉迷了......

目前我的 Claude 快用 7 天了，账号是一年半以前注册的，当时就泄露了不少ip，近些天我直接坐飞机上不下来了（虽然不小心在手机上 leak 了两次），不知道啥时候会被封，总之能用且用。和 GPT 对比的话我感觉我现在就赚了这 20usd 了......

Btw 提醒一下为啥 Leak 对 Claude 影响很大，因为 Claude 他竟然没有被 GFW 封禁你敢信。你是可以访问 Anthrohpic 官网的，因此你下飞机后不小心 打开Claude / 访问官网你的信息都是泄露给 Anthrohpic 了的。所以说 IP Leak 也是很重要的一环。
