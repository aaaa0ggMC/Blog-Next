# Ended But Endless
<np>贪婪真的有种奇怪的魔力，虽然我有很长时间是人在上课，电脑在寝室挂机，但是我自己在这周竟然花了大部分空余时间慢慢玩着贪婪，眨眼间就玩了80小时左右了：</np>

<Img content="/AuAvcsDDIUxP4UvuhvElbPrXQxUA585W8DV_eYmWBc5b1ANNKN5-.png" />

<np>整个历程很长，由于贪婪是一个魔改程度限制程度都很高的整合包，因此我就不赘述我的历程了，这里简要讲一下我干了什么，重点放在我的感受。</np>
<np>当我把大前期走完后我意识到了自己的存储必须要提上日程，花了点时间，我搭建了一个工作平台，并忍着东西越来越乱的恶心感觉把AE存储做了出来，顿时，我便感觉世界清净了，一切神清气爽。矿物方面我一直都在发展MysticalAgriculture，开始的时候就是ActualAdditions的Farmer收割，速度慢的要死，同时我种子也不足。某天刷视频看到一个博主通过MCA里指挥老婆/孩子进行收割活动必定爆一个额外种子，于是我便整了个“人力”农田，火速和NPC结婚生娃获得了两个免费劳动力给我管理农田。不过这些人物不具备自动码放东西的能力，因此我还需要定期去他们背包里面掠夺一下。</np>

<Img content="/72OPMSknAL_TQdqd8aGaxJwV5R1-LsAAy_yKk4dWULhKbIXM.png" />

<np>既然有了AE，那么用电就成了个问题，特别是当你叠起无线传输器的booster时，32个booster 200b访问距离需要将近400rf/t，我刚开始选择的是ThermalExpansion的SteamDynamo，后面换成了DirectDynamo(使用红石发电)，虽然能支持小型使用，但是这导致我的红石出现了短缺。于是我便一直在想怎么解决能源危机。不过，解决能源危机之前，我需要解决我的用铁危机。我的铁存量在前10h基本上没超过100，我刚开始想着MysticalAgriculture + AA Farmer，但是这速度不如我去暮色挖铁，后面我便用TE(似乎)的WateringCan + 免费劳动力产出了很多铁种子，经过很长时间的繁殖，现在不缺了，铁的存量在800+。</np> 

<np>之后我不太想推进AbyssalCraft主线，于是在这个阶段不断完善我能完善的科技，把EnderIO ThermalExpansion都推了推，但是一直不推进主线显然是不对的，于是我便“火速推了推”主线，打完了第一个boss.但是当我想着我终于能打凋零时才发现我还需要打盖亚守卫者。</np>

<np>OMG,我又要开始无聊的旅途了，我建造了一个泥土平台用于植物魔法，然后花了很久挂出一点魔力做了9多爆炸花，结果我这个版本粘液块复制TNT是被禁用的，但我也没放弃，开始我想着在远处生成TNT然后推到花附近，但是这样容易炸膛破坏我没有claim的区块的地形。因此我又开始找寻，发现了无需粘液块的TNT复制机器，一建造，哈哈，我的魔力危机算是彻底解决了。我拿红石钟 + 竖向红石火把列把红石钟的信号往上传，接着搞了个侦测器把连续信号转变为脉冲信号，我的TNT复制机器算是完成了：</np>

<Img content="/oWVZ9XVlH181HQX8wV4QbNB-2FkIArLU5YsLWPyfUXbDY7MTmP-q.png" />

<np>魔力危机解决后植物魔法也就没那么坐牢了，我很快做了个平台打盖亚，但是我电脑太卡了（Linux上玩是这样的），加上我技术也菜，于是我选择反向马镫，用钩爪把自己勾出去从而避免恶心的魔法伤害，由于盖亚后面会召唤怪物，而这些原版怪物在难度系统的加成下超标炸了，于是我搞了个坑从了避免近身，这样我只要举着盾牌等待盖亚无敌时间一过继续撸撸撸就行。</np>


<Img content="/qp-1OzT946UUYGar-GstAr5CwbTSxRYfUnBa5Gn4UgkYON2rJL5IyqI.png" />

<np>在玩植物魔法的时候偶然发现Mana Fluxfield这个玩意（原本我在想有没有mana->rf的东西），我一看，我的天啊，这个单个方块最快1600rf/t产出，于是我经过一段时间努力直接搞了个阵列，，打完盖亚换成盖亚发射器 + 火花传递速度基本拉满了：</np>

<Img content="/7doqexiHGzRdBf9ljhZbcggOktWJT4Efm-ghq_cRnSz5Ddc.png" />

<np>现在我如果有存储模块，一秒钟有0.1MRF的能量剩余，虽然应该比不上核电，但是绝对超过大部分发电了。关于能源方面我是缓存大王，我AE的EnergyAdaptor上面接了2*3.2MRF的缓存，然后我更是做了8个TE的电池并且都升级到了信素，因此这一块缓存就是8*32M = 256MRF.这么多缓存能量掐指一算我大概能挂机5h(完全不产能的情况)。</np>

<np>之后就是打凋零，这个HauntedSlime是真的超标，伤害高还会隐身。不过邪恶的我还是有逃课路线，打一次凋零基本不掉血，操作便是找一块水池（我是原本打算去主世界地底让铁傀儡打结果那个地方刚好有水池于是凑巧发现的），然后放个铁傀儡吸引凋零开始的仇恨，之后再他们俩互殴的时候把凋零用反向马镫背起来，确保自己身上有类似InventoryPets中的墨鱼的那个机制（水中快速移动，水下呼吸）后便可以背着凋零在这个大水池里面绕圈圈了，简直不要太爽。</np>

<np>DefiledLands的第一个Boss（忘了）和和第二个Boss（似乎是什么呻吟者？）都比较好打，没啥机制，我直接那laser gun射射射轻松击败。于是我便可以开始做耐钢了，跟着教程搭建了一个多方块结构，等待，产出：</np>

<Img content="/ul1SvRRJesqfmlHEqU-uNUiAGjXK6EorGXI4wEgcGQYetCwyyatwoA.png" />

<np>有了耐钢，轻松做出EnderCharm,我终于可以去打末影龙了！！！我才突然发现我对比贪婪II的旅途明显要舒适不少，贪婪II我玩了100个小时没多少挂机也才要去打末影龙，然后直接卡在紫焰人，我发现贪婪1竟然没安装DivineRPG,太爽了！这才是一个不怎么硬性坐牢的旅途啊，我这次挂机了20多h也只花了80h就超越上次进度了（甚至贪婪II我直接跳了耐钢，因为任务奖励了部分）。</np>

<np>激活末地门，I've reached the end.</np>

<np>末影龙我拿激光枪射死了，我发现这玩意儿确实超标，要不是旁边有SpectreSlime一直恶心我，我甚至可以不死就打完，原因就是激光射到末影龙身上尤其是头部似乎会触发硬直，于是我直接硬控末影龙。打完龙后，难度已经飙升到了640。我”测试了一下“，发现哪怕我护甲已经60左右了，血量70左右，TNT爆炸一下我要是吃满伤害还是会立马暴毙，属于是永远都舒服不起来。</np>

<np>之后做了做codense matrix给镐子然后挖Draconium(挖掘等级一样但是Draconium是烂大街的东西而codense matrix做起来很麻烦)，全套Draconium，同时我还是忘不了FluxElectrum爽爽的Energized特性（可以充能，先使用电量），于是都打上了。</np>

<np>虽然末影龙打完了，但是主线进度才过了50%，整个游戏进度更是应该只有40%。所以......接下来还是一场endless的旅途。</np>
