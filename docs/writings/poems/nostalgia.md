# <p align='center'>Nostalgia</p>
<div align='center'>

媒体记录的常是美好 <br/>
文字写下的终是平庸 <br/>
你用现在覆写过去 <br/>
写的是过去的不同 <br/>
还是现在的苦痛？ <br/>
<br/>
回忆使我内耗 <br/>
回忆却又令我放松 <br/>
我愿意顺着你的指引 <br/>
堕入这一场场慢节奏的千禧梦

</div>
