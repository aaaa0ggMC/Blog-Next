# 占据

> 2026.4.13日晚 完整度:20%


<np>
我发现自己出现在了大学的寝室,但是教室又是高中那种,我感受到了一种监禁的感觉,感受到了大学正在变成高中的样子.
</np>

<np>
我们一直都在跑操,跑到完全没有自己能够支配的时间,跑到没时间休息.
</np>

<np>
于是,我便在上课时直接逃课了,但我并没有去哪儿,而是去了别人的课堂,把他们课堂黑板上的贴纸折成了一个个口罩,旁边听课的老师看到我这个便夸我能学这么早(时间似乎是六点多,也不知道和上面的逃课是不是顺序时间关系),我冷不丁的说我是王者荣耀大蛇.
</np>

<np>突然,我感觉到自己提起完全不想干的东西很不合适,我产生了罪恶感,感觉自己像一个嘉豪.</np>

<np>
下课后我走在走廊上,朋友(于XX)找我似乎要约一个什么,结果发现跑操把时间都占了.
</np>
