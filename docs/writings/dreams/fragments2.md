# 碎片化旅行2
> 2026.3.20日晚 完整度:40%

## 骑行
<np>我到了老家,发现大门换成了电子锁,我试着拿指纹解锁,没有录入.于是我便拿校园卡刷了一下感应区域,总算录入了自己的指纹,进了屋子.进了家门我才发现所有门锁都换成了这种黑不溜秋门把上指纹感应的东西,同时家里面也挤满了形形色色的亲戚,我想去上个厕所,恰好看到一个我不认识的亲戚上完回来,他为什么可以直接指纹解锁?我在一瞬间感到了纳闷.</np>
......
<np>我骑上了我的自行车(现实里是我的ATX620),自由地离开了我的老家,在一个个弯弯绕绕的地方感受着离心带来的独一无二的感觉.</np>

## 生物,博物馆
<np>我和朋友到动物园还是什么地方旅游,我骑行在这一个个建筑中,到了博物馆,博物馆里似乎很奇妙,但是我醒来已经忘了.</np>
......
<np>我们似乎触发了什么危险.一个人(像是我的父亲)骑着摩托车告诉我们跟着他前往博物馆,有事干.于是我坐在朋友摩托车后,那个人用着导航走在前面,我们则紧紧跟着地上的黄色轨道前往所谓的博物馆.黄色轨道刚开始还不错,但是约到后面越是诡异,其出现了分叉,出现了过山车那种回旋,我们感觉很奇怪,但还是开着摩托车在上面.直到它把我们带到了一个山顶,我们才惊呼:"这不是博物馆!"</np>
<np>我的视线转到了空中的一只只昆虫中,他们扫描着我们一个个人,扫描到我的时候似乎发出了信号:"面部匹配中,匹配到'施一公',匹配成功,准备基因掠夺"(我从初中开始到高中对生物好感都不错,而且初中一直都是生物课代表,高中生物也很好),不过紧接着又发现我似乎没有在生物学上的爱好于是似乎暂停了信号(高中物化生组合大学学习计算机).我们看着后面乌泱泱的像昆虫又像机械的大军,直接冲出了崖壁,在空中飞出了抛物线.</np>
<np>到达地面后同伴告诉我干脆我们用导航吧,于是我开启导航,冲出所谓的主道,在草原上开着摩托车狂奔,等远处的博物馆出现,我们才发现其坐落在海边,根本没有正常通往的马路,我们从沙滩往上开,发现那个人已经到了等在那儿.我们说自己导航错了,他拿了一个奇怪的装置给我,告诉我套在脚上,那个装置把我的小腿裹得很严实,其上部开口,有着一块铁丝网.我下意识认为这是用来防虫子的,于是把自己的袜子提了提(因为没裹到脚踝),他却告诉我没必要这样.</np>
<np>没必要哪样?博物馆里有什么?到底是什么危险?</np>
<np>没等我进去找寻答案,梦醒了,我也只能专注地回忆梦境,写下这篇记录.</np>
