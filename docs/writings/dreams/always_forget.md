# 总是遗忘
> 2026.3.27日晚 完整度:20%

<np>我和朋友开始了一场旅行,我们经历完旅行后(中间过程完全忘记了)便找了个酒店休息.由于酒店的被褥实在单薄,我便把自己寝室里的被子带到了酒店(在梦里,这个被子似乎是大学宿舍的一套,是学校冬天填表就送的).之后我和朋友到了那时空无一人的我的老家,准备再住一晚,我们把东西放好.一个人在炕处搞了个类似床的小平台便躺了上去.另一个人问我:"我们两个不会要睡外面吧?"</np>
<np>我开始也是迷茫带点遗憾,不过当我不知随手还是刻意打开一扇门后,一张大床出现在了里面,我们欣喜若狂,躺了上去.</np>
<np>之后,不只是那个睡炕上的朋友还是其他人到了房间,看见我们睡着大床,很是惊讶.</np>
<np>......</np>
<np>旅行完毕,是时候会学校了,我回到的学校是我高中时期高一高三的复合体.我的同桌是和我找了个地方睡觉的那个人.到了学校,我才发现:我忘记带回被子了.于是我一次又一次地在梦里告诉自己,告诉朋友:"我被子落在酒店了,我要找个时间去拿一下".</np>
<np>朋友挺冷静的,说:"工作人员应该会收好."</np>
<np>这时,我的其他几个朋友,在梦里我最清晰的是龙某和于某某,他们突然出现在门口,大喊:"要不要去打羽毛球啊?"我自然是一口答应.</np>
<np>可是当我去找我羽毛球拍的时候,我发现自己最钟爱的羽毛球拍也落了.现在我课桌边上的要么是残疾球拍要么就是垃圾球拍.</np>
<np>"完了,我球拍也忘拿了."</np>
<np>"那我们先走了."</np>
<np>我经同桌允许后拿同桌放桌上老年机准备打爸爸的电话让他给我送一下,老年机右边是纯数字按钮,左边则是九宫格字母+数字按钮,我记得爸爸的电话是"XXXXX",于是我在右侧依次按下这些按键,但是不知道是不是按键失灵还是怎么的,过了一会儿后屏幕上出现的数字便意义不明了,我很纳闷:"我按的不是XXXXX吗,怎么变成XYZWDE"了?</np>
<np>我把目光投向了左边的混合型按钮,觉得是右边按键失灵,我按下几个按钮......</np>
<np>我到了一个昏暗的空间,这个空间似乎有很多奇怪的怪兽,我也忘了自己是要打电话的......</np>
<np>我也忘了后面的故事了.</np>
