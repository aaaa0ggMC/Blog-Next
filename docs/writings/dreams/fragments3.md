# 碎片化旅行3
> 2026.9.26日晚 完整度:10% 

## 关门大吉

大家似乎都在毁坏商铺，而我们就是开商铺的，于是我们直接拉下卷帘门，等待着外界或许永无止境的破坏。

一个人隔着卷帘门和我们聊了很久，似乎是我们的熟人。

## 死亡商铺

......

或许是出于好奇，我在一个商场中绕了很久，甚至钻入了许多狭小的缝隙，到了一个漆黑的店铺。

大厅呈方形，一条条绳子如同鱼钩从天花板垂落下来，上钩了一个个吊死的人，或许这也只是模特。我拿起手机拍照后，小心翼翼地绕开这些诡异的东西，到了一条长廊，长廊的尽头终于出现了门，打开门后，眼前的场景变成了各种办公大楼那种经典的“走廊+门牌”的布局，而这个房间处于楼的角落，被一扇玻璃门与其他房间隔离着。

不知为啥玻璃门没开，我感到害怕直接往楼下跑，撞见了一个疑似是这边办公的人。他意味深长地盯着我，我急忙解释道：“我来这边找厕所，厕所在哪里？” 可他还是带着那迷之微笑，于是我又解释说：“我很急。” 

我以为这样他就“理解”了，没想到他下一句话却让我入坠冰窟：“厕所在一楼。”

我急忙下楼然后远离这栋建筑。
